This is the only tab where the business owner does real work. Each test call is a short block of fields. Persona and goal drive the simulated caller; facts are what it can answer when the bot asks, so they must match the test data the bot’s tools return. Success criteria and policies are what the scorer checks. Split marks a call as practice, which the coach learns from, or exam, which is held back to catch over-fitting. Voice and noise only matter for audio runs. Save validates the file before keeping it.

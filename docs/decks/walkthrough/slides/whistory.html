Demo data shown. Run IDs are the date and time the run started.

History is the audit trail. Every Evaluate and Auto-improve run is saved with all its calls, scores, audio clips and, for coaching runs, the original instructions. Click any row to reopen it exactly as it finished, which is useful for comparing this week’s bot with last week’s, or for showing a stakeholder the evidence behind a change. If a run is still going, clicking it shows live progress. When deployed on Google Cloud, runs live in a storage bucket so nothing is lost on restart.

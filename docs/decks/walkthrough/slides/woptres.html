This is the screen to spend time on. The chart shows the score per round: blue for practice calls, grey dashes for exam calls. In the real run on our demo agent, the coached version raised practice calls from 0.58 to 0.80 and exam calls, which the coach never saw, from 0.78 to 0.85, so it was kept. If exam calls had fallen, it would have been rejected as a change that only learned the practice calls; a rewrite that drops a tool is blocked without testing. Each row lists what the coach saw and what it changed. Diff compares instructions, Episodes opens that round’s calls, and Apply writes that version to the bot.

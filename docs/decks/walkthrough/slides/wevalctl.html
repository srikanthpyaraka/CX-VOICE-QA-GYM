Tab 3 · Evaluate

Four settings, then Run evaluation

Trials

How many times each test call runs. Use 2–3 to smooth out lucky or unlucky calls.

Mode

Text turns run in seconds. Full audio speaks every line, like a real call.

Background noise

Audio only. One noise for every call, or each call’s own setting.

Use tool fakes

On by default. The bot’s order and account lookups use pretend data.

Demo data shown. The blue bar fills as calls finish; only one run can happen at a time.

Evaluate tests the bot exactly as it is today and changes nothing. Trials repeats each call, because AI callers and scorers vary a little from run to run. Text mode is the quick daily check; full audio is slower, about one to three minutes per call, but tests listening and speaking. Background noise applies only to audio. Keep tool fakes on unless the bot is wired to a safe test system, so no real orders or accounts are touched. Press Run evaluation and watch the progress bar.

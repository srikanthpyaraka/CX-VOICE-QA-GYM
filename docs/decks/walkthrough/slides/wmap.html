The map

Five tabs, used left to right

Tab 1

Connect

Point the app at a Google agent and pick which one to test

Tab 2

Scenarios

Write the test calls and the house rules

Tab 3

Evaluate

Run every test call once and get a report card

Tab 4

Auto-improve

Let the coach rewrite the instructions, round by round

Tab 5

History

Reopen any past run and its results

Call pop-up: click any call in a results table to read, replay and see why it was scored that way

Diff pop-up: compare the coach’s new instructions with the original, word by word

Give the audience the map before the detail. The tabs run left to right in the order you use them. Connect and Scenarios are set-up; you do them once per agent. Evaluate is the health check you run any time. Auto-improve is the coaching loop. History keeps every run so nothing is lost when you close the browser. Two pop-up windows open from the results: one shows a single call in full, the other compares old and new instructions.

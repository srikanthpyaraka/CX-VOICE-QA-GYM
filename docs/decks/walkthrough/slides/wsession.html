Close with the order of operations for a first real session. Steps one to four set up and measure: connect to a copy of the bot, replace the sample calls with your own, run a quick text evaluation and sanity-check the scorer against your own judgement, then run the audio version. Steps five to seven improve and confirm: two coaching rounds, review the kept change with the bot’s owner and apply it, re-run Evaluate to confirm the gain holds, and release it the usual way. Every step leaves a run in History as evidence.

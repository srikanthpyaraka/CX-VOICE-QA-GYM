Tab 4 · Auto-improve

Same settings, plus rounds and a safety tick-box

Iterations

How many coaching rounds to try. Each round re-runs every test call, so audio rounds take a while.

Sandbox tick-box

Required. Confirms this is a copy of the bot, because trial instructions are written to it during the run.

Start loop

Saves the original instructions, runs a baseline, then coaches. The original goes back at the end.

Demo data shown. Trials, mode, noise and tool fakes work exactly as on the Evaluate tab.

Auto-improve has the same four settings as Evaluate plus two more. Iterations is the number of coaching rounds; two or three is a good start, and fewer in audio mode because each round re-runs every call. The tick-box is a deliberate speed bump: the loop temporarily writes trial instructions into the bot, so it must be a copy, never the live customer-facing bot. When you press Start loop the app saves the original instructions to disk, scores the bot as it is, then starts coaching. Whatever happens, even a crash, the original instructions are put back at the end.

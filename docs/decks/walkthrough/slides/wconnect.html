Tab 1 · Connect

Tell the app where the agent lives

You enter

Google Cloud project, location and app ID, then click Connect.

It shows

Every agent in that app in a dropdown, and the chosen agent’s current instructions.

If it fails

A red message says why: wrong app ID, no access, or not signed in to Google Cloud.

Real connection to the demo agent in project enrichment-conv-sf, location us. The app remembers the last project and app ID in your browser.

Connect is a one-time step per session. The three boxes are the agent’s address in Google Cloud; the app ID is in the CX Agent Studio console. After Connect, the header shows the full address, the dropdown lists every agent in the app, and the grey box shows the chosen agent’s instructions. Those instructions are what gets tested and, in Auto-improve, rewritten. Access uses the signed-in Google Cloud account; nothing is typed in for passwords.

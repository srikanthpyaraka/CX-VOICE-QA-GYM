Real run, 19 Oct 2026 · 1 coaching round, 6 calls each side · exam calls are never shown to the coach · kept, awaiting Apply

This is the self-improving part working on a real agent. The coach read the failed and low-scoring calls and wrote seven targeted changes: mask email addresses, read back corrected order numbers, require full verification before an address change, handle transfer requests properly, keep spoken replies under about forty words with one question at a time, and rebalance the persona from thorough to clear and concise. Every test call was then run again. Practice calls rose from 0.58 to 0.80, and the exam calls, which the coach never saw, rose too, from 0.78 to 0.85, so the change was kept. The agent was put back to its original instructions automatically; the improved version only goes live when a person reviews the diff and clicks Apply. One caution to say out loud: scores vary from run to run, which is why we use repeated trials before trusting small gains.

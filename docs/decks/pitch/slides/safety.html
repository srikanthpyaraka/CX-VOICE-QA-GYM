Step 6 · Approve

Nothing reaches customers without a person saying yes

Coaching runs on a copy of the bot, never the live one

The original instructions are saved first and put back after every run

A reviewer clicks Apply on the version they want, or Restore original

Test calls use pretend back-end systems, so no real orders or accounts are touched

RISK AND CONTROL (45 sec). Three safeguards. One: it only coaches a copy of a bot, never the live one. The original instructions are saved first and put back automatically, even after a crash. Two: nothing changes without a person. You review the diff and click Apply, and it still goes through our normal release process. Three: test data, not customer data. It runs inside our own Google Cloud project, the app is private behind Google sign-in, and every run is kept as an audit trail. IF ASKED “what if it breaks a live bot?”: It can’t touch one; see point one. IF ASKED “is customer data involved?”: No. Fictitious test data, inside our own project, and results go to BigQuery only if we switch that on.

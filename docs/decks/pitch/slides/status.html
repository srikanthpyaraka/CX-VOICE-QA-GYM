Be straightforward about maturity. The application is built and has now run end to end against a real Google CX Agent Studio voice agent that we created in our own project: six simulated calls, five passed, and the scorer found real rule breaks. The code is on GitHub. Running it surfaced practical lessons: a new project’s default quota allows roughly one agent reply per minute, so a full test run takes most of an hour until the quota is raised; that is a standard request in the Google Cloud console. The coaching run on the demo agent is in progress. Remaining limits: simulated callers cannot interrupt the bot, keypad input is not simulated, and the AI scorecard should still be checked against a human reviewer before anyone relies on the numbers.

Be straightforward about maturity. The application is built and has now run end to end against a real Google CX Agent Studio voice agent that we created in our own project: six simulated calls, five passed, and the scorer found real rule breaks. The code is on GitHub. Running it surfaced practical lessons. A new project’s default quota allowed roughly one agent reply per minute; we requested an increase and it was approved within minutes. One coaching round then raised the practice score from 0.58 to 0.80 and the exam score from 0.78 to 0.85. Scores do vary from run to run, so we use repeated trials before trusting small gains. Remaining limits: simulated callers cannot interrupt the bot, keypad input is not simulated, and the AI scorecard should still be checked against a human reviewer before anyone relies on the numbers.

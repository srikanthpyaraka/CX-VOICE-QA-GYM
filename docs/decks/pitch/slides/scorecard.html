THE SCORECARD (45 sec). Every call, same scorecard, same weights. Did the caller get what they needed, were the house rules followed, did it make anything up, did it sound right on a phone. Each problem comes with a written reason tied to the turn number. IF ASKED “can we trust an AI to grade an AI?”: Not blindly, and we don’t. Every verdict shows its reasons, so anyone can check it. Week two of the pilot compares it with a human reviewer on 20 calls; if they disagree, we know before relying on it. IF ASKED “don’t scores bounce around?”: They do. The same untouched bot scored 0.74 in one run and 0.58 in the next. That’s why we repeat calls and only keep a change that clears a margin. The 0.58 to 0.80 gain you’ll see shortly is well outside that noise.

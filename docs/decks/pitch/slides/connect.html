Step 1 · Connect

Does it find the voice agent from the app ID?

Yes, automatically

  • You type three things: Google Cloud project, region, app ID
  • It connects and lists every agent inside that app
  • It reads the chosen agent’s current instructions and shows them on screen
  • It then calls that agent through Google’s own testing channel

You still decide

  • Which agent to test, picked from a dropdown, since an app can hold several
  • What the test calls are about. It does not invent them from the agent; a business owner writes them
  • Whether an improvement is applied
This answers the most common question directly. The app ID is enough for the tool to find the bot: it connects to Google Cloud, lists the agents in that app, and reads the instructions of the one you choose. What it does not do by itself is decide what to test. Someone who knows the business writes the test calls, which is the next slide. That is deliberate: the tests should reflect what real customers call about, not what the bot already knows how to do.
